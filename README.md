## Project Overview

An AI-powered Digital Twin Learning Platform that combines virtual electrical experiments with real hardware using Arduino. Students can perform experiments, receive AI guidance, complete assessments, and interact with physical trainer kits.

## Features

- AI Teacher
- Digital Twin Experiments
- Interactive Wiring Validation
- Automatic Assessment
- Student Reports
- Staff Approval Workflow
- Arduino Integration
- Real-Time Hardware Control
